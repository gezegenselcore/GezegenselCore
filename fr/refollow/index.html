ReFollow

Analyse de votre graphe social

Disponible sur Google Play

ReFollow est une application qui vous permet d'analyser vos abonnés et abonnements Instagram. L'application ne se connecte pas à votre compte Instagram et ne demande pas votre mot de passe. L'analyse est effectuée uniquement à partir du fichier de données JSON/ZIP que vous téléchargez via la fonction « Télécharger vos informations » d'Instagram.

  • 🔑

    ReFollow ne demande jamais votre mot de passe Instagram.

  • 📦

    L’analyse utilise uniquement l’export ZIP officiel (JSON).

  • 📱

    Vos listes restent sur le téléphone ; elles ne sont pas envoyées.

  • 🚫

    ReFollow n’accède jamais à l’application Instagram.

Avec ReFollow vous pouvez voir :

  • Comptes qui ne vous suivent pas (gratuit : 5 premiers ; liste complète Pro)
  • Les comptes qui vous suivent mais que vous ne suivez pas (Fans, Pro)
  • Les abonnements mutuels (Pro)
  • Changements d'abonnés entre analyses (Pro)
  • Date de suivi (export JSON) et tri par date
  • Liste de suivi — marquer des comptes, alerte en cas de changement
  • Changements de nom d'utilisateur possibles entre deux exports
  • Résumé santé du suivi sur l'accueil (taux et tendances)
  • Sauvegarde chiffrée et restauration — gardez vos snapshots en changeant de téléphone (Pro)
  • Carte résumé partageable (PNG) — ratios et tendances sans listes de noms
  • Rapport PDF snapshot — 5 dernières analyses (Pro)
  • Multi-comptes — analyser plusieurs comptes Instagram séparément (Pro)
  • Exporter les listes par catégorie en CSV et les partager (Pro)
  • Verrouillage biométrique de l'app (empreinte / Face ID)
  • La version gratuite contient des publicités. Ta première analyse est sans pub, les suivantes se débloquent avec une courte publicité.
  • Les demandes d'abonnement reçues; les demandes d'abonnement envoyées encore en attente (Pro)

Comment l'utiliser ?

  1. 📲

    Créer l’export

    Dans l’application Instagram : Ouvrir Profil → menu ☰ en haut à droite
    Centre des comptes → Vos informations et autorisations
    Télécharger vos informations → Créer un export
    Transférer sur l’appareil → choisir JSON + Depuis toujours
    Démarrer l’export

  2. 📂

    Télécharger le ZIP

    Attendre 5–15 minutes (Instagram envoie aussi un e-mail quand le ZIP est prêt)
    Revenir au même écran → appuyer sur Télécharger
    Enregistrer le fichier ZIP

  3. ✨

    Lancer l'analyse

    Sur l’écran d’accueil de ReFollow, importe le ZIP téléchargé depuis Instagram ; l’analyse démarre automatiquement.

Obligatoire: Le format JSON et Toute la période doivent être sélectionnés.

Politiques de sécurité ReFollow

Pourquoi nous ne risquons pas votre compte

  • ⚠️

    Comment fonctionnent les apps qui demandent un mot de passe

    Ces applications ouvrent dans leurs propres écrans un formulaire qui ressemble à une « page de connexion Instagram », mais qui est faux — ce n’est pas la vraie adresse instagram.com. Dès que vous saisissez votre mot de passe, chaque frappe est copiée directement vers leur serveur. Votre mot de passe n’est plus à vous ; il est entre les mains du propriétaire de l’application.

  • 🚨

    Les risques des applis qui demandent ton mot de passe

    • Votre compte utilisé comme bot publicitaire (vente de likes/abonnés)
    • Bannissement définitif par Instagram pour « connexion suspecte »
    • Accès à vos messages privés et photos
  • 🛡️

    La différence ReFollow (ZIP)

    Nous ne demandons jamais votre mot de passe car nous n’entrons pas « à l’intérieur » de votre compte. Nous traitons le fichier de données officiel d’Instagram (ZIP) sur votre appareil. Vos données ne sont pas envoyées sur Internet ni sur un serveur — elles restent uniquement sur votre téléphone.

  • ⏱️

    Passer deux minutes à importer votre fichier de données est bien plus sage que de perdre votre compte.
